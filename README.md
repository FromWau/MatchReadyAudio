# Match Ready Audio

Hear match intro music when tabbed out. Temporarily enables "Sound in Background" for 7 seconds when joining a match.

## Features

- Hear match intro music when tabbed out
- Automatically skips if "Sound in Background" already enabled
- Restores original setting after 7 seconds
